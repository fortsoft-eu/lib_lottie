# lib_lottie

## English (United States)

Fork of [desktop-app/lib_lottie][upstream], used by [fortsoft-eu/tdesktop][parent]:
Telegram Desktop 7.1.3 with a Windows 2000-style GUI.

Lottie animation playback, rendering, and caching. Local changes make
animated toast icons follow the Windows 2000-style interface text color.

Build this library as part of the parent project, not as a standalone application.
